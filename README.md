# ***Algoritmos em JavaScript***

## Arquivos e seus significados

### **Pasta *api***

#### *bancos.js*

- Código que utiliza-se de uma API para obter as informações básicas de todos os bancos do Brasil, assim gerando um arquivo Markdown (bancos.md).

#### *feriados.js*

- Faz o mesmo de *bancos.js*, porém com todos os feriados brasileiros do ano selecionado por meio de endpoints.

### **Demais Arquivos**

#### *alunos-notas.js*

- Validação usando forEach para verifiar quais alunos foram aprovados e quais foram reprovados.

#### *calculadora.js*

- Calculadora básica contendo apenas as quatro funções fundamentais da aritmética (+, -, / e *), utilizando de readLine para que haja interação com dados externos.

#### *carrinho-1.js*

- Desenvolver uma função que calcule o valor final de um pedido aplicando um cupom de desconto percentual e exiba um resumo formatado.

#### *desconto.js*

- Pequeno sistema de cálculo de desconto de um produto, em que se obtém os referidos dados a partir de readLine.

#### *idades.js*

- Um  pequeno algoritmo que recebe um array de pessoas e suas idades, separando-as em maiores de idade (>= 18) e menores de idade (< 18) e calcula também a média das idades de cada grupo.

#### *jogo.js*

- Jogo em que o usuário tem de acertar o número de 0 a 100 que o sistema escolheu.

#### *lista-compras.js*

- Algorítmo simplíssimo sobre uma exibição no console de um carrinho de compras de uma loja online, usando-se de *for*.

#### *logica.js*

- Anotações de aula
